# 幻兽帕鲁专用服务器：1.0正式版按在线人数选配置，一键开服不折腾，新手也能自己搞定联机

《幻兽帕鲁》1.0 正式版在 2026 年 7 月 10 日上线，结束了两年半的抢先体验，Steam 同时在线人数一度突破 85 万 [1]。老玩家回坑、新玩家入坑，结果都撞上同一堵墙：游戏自带的联机最多只支持 4 人同服，而且房主一关电脑，世界就跟着下线。

专用服务器就是为这件事准备的。不用等别人开机，存档在云端，异地朋友随时能进。真正需要你动手决定的其实只有两件事：**开在哪个平台上，以及给多少内存**。

## 1.0 之后，"能开服"和"开得稳"不再是同一件事

抢先体验阶段，8GB 内存的机器也能凑合跑。1.0 把地图做大了，新增的世界树与天阳乡两个终局区域 [2]，加上 72 只新帕鲁，服务端的负载明显上去了。

几个已经确认的事实值得先摆出来：

- 官方推荐配置是 **4 核 16GB**，8GB 能启动，但内存不足导致崩溃的概率更高 [3]
- 硬盘必须是 SSD，低速盘不只是加载慢，严重时会把存档写坏
- 服务端默认使用 **UDP 8211** 端口通信，这个端口不开，别人就连不进来
- 服务端内存占用会随运行时间、帕鲁数量、据点规模持续累积，不是启动时就吃满 [3]

最后一条是很多人踩坑的地方。开服第一天很流畅，第三天开始随机掉线，第四天直接崩——通常不是 CPU 不够，是内存被吃光了。

## 帕鲁服务端吃什么：内存优先，CPU 其次，硬盘别省

按同时在线人数来对照，比按"配置越高越好"来选要省钱得多：

| 同时在线人数 | 建议 CPU | 建议内存 | 带宽 | 说明 |
| --- | --- | --- | --- | --- |
| 2–4 人（好友小队） | 2–4 核 | 8GB 起 | 5–10Mbps | 据点规模小时可行，配合定期重启 |
| 4–8 人 | 4 核 | 16GB | 10Mbps | 对应官方推荐值，大多数玩家落在这档 |
| 8 人以上 / 长期大基地 | 4 核及以上 | 32GB 以上 | 10Mbps 以上 | 存档持续变大，内存需求上升明显 |

> 官方写的 4 核 16GB 是推荐值，不是最低门槛。真正的边界取决于你们建了多少基地、养了多少帕鲁、世界跑了多久。

预算有限的时候，把内存从 8GB 拉到 16GB，比把 CPU 从 4 核堆到 8 核更有意义。帕鲁服务端的崩服绝大多数是内存溢出，不是算力不足。

## 雨云给帕鲁准备的三条开服路线

同一个平台，三种产品形态，难度和自由度完全不同 [4]：

### 雨云面板：点几下就能开，适合完全不想碰命令行的人

雨云自研的高可用游戏面板，基于 K8s 集群，支持一键开服、CPU 升降级、可视化配置修改、备份和 MySQL。幻兽帕鲁已在支持列表里，下单后等几分钟服务器自己就开好了。

它的配置文件是**可视化界面**，`PalWorldSettings.ini` 里的经验倍率、掉落倍率、最大人数这些可以直接改，改完保存重启就生效，不用记路径。

### MCSM 面板：开源面板，网页操作 + SFTP

MCSM 是开源、分布式的服务端管理器，同样支持幻兽帕鲁一键开服，全程网页操作，带实例管理和文件管理。要传文件改配置，用 SFTP 就行。

有一个细节要注意：如果你开在宿迁地区的面板，连接时要选 **UDP 专用地址**，选错了会出现"服务器已开但进不去"的情况。

### VPS：自由度最高，独立公网 IP

VPS 相当于给你一台完整的 Windows 或 Linux 机器，可以多开服务端，可以装别的程序，开放 15 个端口，支持附加独立公网 IP 和备份。

- **Windows 路线**：购买时勾选"帕鲁预装"，或者在"重装系统或软件"里补装。装好后远程桌面连上去，双击桌面上的「启动幻兽帕鲁服务端.bat」，玩家通过 `你的IP:8211` 进服。配置文件在 `C:\PalServer\Pal\Saved\Config\WindowsServer\PalWorldSettings.ini`
- **Linux 路线**：用 SteamCMD 拉 app_id `2394010`，通过 systemd 做成服务实现开机自启。不熟悉命令行的，Windows 更省事

三种形态怎么选，一句话总结：**只想开帕鲁、不想折腾 → 雨云面板；想用开源面板、需要传文件 → MCSM；想一台机器干多件事 → VPS。**

## 开服实操：从注册到朋友进服

1. 注册账号并领取新用户首月 5 折券
2. 进控制台，在"总览"或"云产品"里找到游戏云入口
3. 选择产品类型（雨云面板 / MCSM 面板 / VPS），游戏类型选"幻兽帕鲁"
4. 选机型和配置。帕鲁建议 4 核 8G 起步，长期在线建议直接上 16G 内存档位
5. 选计费模式、区域和公网 IP 方式，确认下单
6. 购买后在"我的游戏云"里点管理，进面板实例控制台，点"开启实例"
7. 等状态变成运行中，面板右侧的对外地址 + 端口就是服务器地址，形如 `hm.rainplay.cn:31740`
8. 游戏里点"加入多人游戏（专用服务器）"，在底部填入这个地址和端口即可

**改配置的标准动作**：把 `DefaultPalWorldSettings.ini` 的内容整段复制到 `PalWorldSettings.ini` 里再修改。直接往空文件里手写配置，经常不生效——这是新手最容易卡住的一步。

如果你想改的不只是经验倍率，还有服务器名、密码、最大玩家数（`ServerPlayerMaxNum`，默认 32），这些都在这份配置文件里。

## 开服后最容易翻车的三件事

**内存吃满导致闪退。** 两个缓解手段：一是设一个每天凌晨的定时重启；二是 Linux 环境下配置 Swap 虚拟内存（`fallocate -l 8G /swapfile` 那一套），能在内存吃紧时顶一阵。但这些都是应急，根本解法还是升配置。

**端口没放行。** UDP 8211 要在两个地方开：系统防火墙（iptables / ufw 或 Windows Defender 防火墙）和云平台的安全组。只开一层，照旧连不上。用 NAT 模式的话，还要在控制台里把 8211 映射出去。

**存档没备份。** 帕鲁的存档会随着游玩不断变大，低速磁盘有写坏的风险。开服时养成立即备份一次的习惯，后面改配置、升级配置前都备份一遍。

## 常见问题

**4 核 8G 到底够不够？**
4 人以内、据点不大，够用，但要配合定期重启。人一多、基地一铺开就会吃紧，1.0 的地图比抢先体验阶段大，12GB 内存的机器已经开始紧张了 [5]。预算允许就直接上 16G。

**必须买独立公网 IP 吗？**
不是必须。NAT 模式下多人共用一个公网 IP，通过端口映射对外提供服务，端口数量足够玩游戏私服。加购独立 IP 的主要好处是独享防御和更干净的地址。

**最多能放多少人？**
配置文件里 `ServerPlayerMaxNum` 默认是 32，但能跑多少人取决于你的 CPU、内存和带宽，不是改个数字就行。公会的默认上限是 20 人（`GuildPlayerMaxNum`），大规模建家时内存消耗会很可观。

**可以先试再买吗？**
可以。云服务器和游戏云产品支持 1 元试用 1 天（每款限 1 次），另外有 7 天内无理由退订。先试用测一下自己所在地区到机房的延迟，比看任何评测都准。

**配置后面能升级吗？**
可以，控制台支持升级配置和重装/切换游戏，面板产品还支持 CPU 机型切换。
